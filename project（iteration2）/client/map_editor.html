操作说明

1. 必须用 http://localhost:3001/map_editor.html 打开（本仓库 Node 服务）。用 test web 的 3000 或本地文件打开会导致 保存 404。
2. 点击地图用底图 <image> 换算坐标，支持浏览器缩放。
3. 主页地图上方的说明、楼块/Gate 的 大小 / 透明度 / 形状 在下方表单编辑；预览区悬停可看到虚线描边（与主页可点击区域提示类似）。
4. 道路可多段：新分段=分叉；路口让两段共用同一坐标点即可衔接。
5. 改完点「保存到服务器」写入 data/block_map.json。
